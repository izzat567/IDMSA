# IDMSA - Seri Anggun Dining Hall Information System

![IDMSA Logo](https://img.shields.io/badge/Project-IDMSA-blue?style=for-the-badge&logo=appveyor)

**IDMSA** (Information System for Seri Anggun Dining Hall) is a **web-based PHP system** developed for **KV Kuala Selangor** to organize dining hall operations efficiently and improve user experience for students and staff.

---

## 🌟 Key Features

- **📅 Meal Schedule** ![Meal](https://img.shields.io/badge/Feature-Menu-orange?style=for-the-badge&logo=google-menu)
  - View daily or weekly dining menus.

- **📝 Complaint & Feedback Portal** ![Feedback](https://img.shields.io/badge/Feature-Feedback-yellow?style=for-the-badge&logo=messenger)
  - Submit complaints or feedback regarding food quality, hygiene, or other issues.

- **📊 Admin Dashboard** ![Dashboard](https://img.shields.io/badge/Feature-Admin-9cf?style=for-the-badge&logo=analytics)
  - Monitor user data, complaints, and meal schedules.

- **👥 User Management** ![Users](https://img.shields.io/badge/Feature-UserManagement-blue?style=for-the-badge&logo=users)
  - Track attendance and dining hall usage.
